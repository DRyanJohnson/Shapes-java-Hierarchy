  Assignment Overview:
For this assignment, I built an object-oriented shape hierarchy in Java to gain more experience
with inheritance, polymorphism, and interface implementation to sharpen my overall coding skills in
Java. The project centers around an abstract base class, AbstractShape, which defines shared
behaviors and implements the Comparable interface so shapes can be sorted by name and then by area.
Four concrete subclasses like Circle, Square, Triangle, and Rectangle extend AbstractShape and
provide their own specific area calculations to be fully tested in the controller. To keep
the code clean and modular, I implemented a ShapeFactory class to handle making new shape objects
separately from the rest of the shape logic. Across the project, I applied the final keyword to
classes, methods, instance fields, and parameters to lock things down and prevent accidental changes
or overrides. I also focused heavily on defensive programming by adding input validation in every
constructor, throwing descriptive IllegalArgumentException errors if any dimensions were zero or
negative. A separate driver class, ShapeTester, inside a controller package, created 20 shapes
total—five of each type with intentional duplicates—to verify sorting logic and ensure clean
console output formatting. Alongside writing the core logic, I wrote comprehensive Javadocs for every
single class, field, and method. I spent about 10 hours throughout the week and weekend designing,
implementing, and polishing the project from start to finish. By analyzing the feedback, I achieved
a zero-warning status across Checkstyle, PMD also I could not get SpotBugs to properly work even
though it read zero but I kept everything aligned with the UWT SET style guide.
